# 🤖 Telegram Face Recognition Bot

A powerful Telegram bot built with Python that lets users:
- Add known faces
- Recognize people in uploaded images
- Compare with celebrities
- Generate face maps
- Get random faces
- Playfully interact using AI!

---

## 📦 Features

- 🧠 Add and name faces from uploaded images
- 🔍 Recognize faces in group or solo photos
- 🌟 Match user faces with celebrity lookalikes
- 🗺️ Generate face similarity maps (with t-SNE)
- 🔄 Share random known faces from your database
- 🧭 Use custom Telegram keyboard for interaction

---

## 🛠️ Technologies Used

- **Python 3.10+**
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) – Telegram Bot API wrapper
- **OpenCV** (`cv2`) – for image processing and drawing
- **face_recognition** – facial recognition built on dlib
- **NumPy** – matrix + numerical processing
- **matplotlib** – for plotting face maps
- **scikit-learn (TSNE)** – dimensionality reduction for maps
- **PIL (Pillow)** – image manipulation
- **asyncio** – for async bot control
